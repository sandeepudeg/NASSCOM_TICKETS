What it does

Full-Stack AI Ticket Management

From ticket ingestion to resolution suggestion — every layer is covered, open source, and self-hostable.

🤖

AI Classification

Classifies tickets into 7 categories (Infrastructure, Application, Security, Database, Storage, Network, Access Management) using Mistral/Phi-3/Gemma via Ollama with confidence scoring.

🔍

RAG-Based Resolution

Retrieves top-5 semantically similar resolved tickets (cosine similarity ≥ 0.70) and generates ranked resolution steps using LangChain or LlamaIndex.

⚠️

Agentic Escalation

Tickets with confidence score below 0.65 are automatically escalated to a human review queue with webhook notifications and override tracking.

📁

Folder Management

Organise tickets into named folders with drag-and-drop assignment, bulk operations, ticket count badges, and cursor-based pagination.

🔁

Pattern Detection

Detects repeated issue clusters (≥3 tickets, similarity ≥ 0.80, within 7-day window) and surfaces automation suggestions to reduce toil.

📊

AI Model Dashboard

Live UI panel showing F1 scores per category, semantic similarity score, LLM-as-judge routing/resolution scores, and model version comparison.

🛡️

PII Scrubbing

All ticket content is scrubbed of PII (names, emails, IPs, Aadhaar) using Microsoft Presidio before entering the embedding pipeline — GDPR/DPDP compliant.

🔄

Continuous Retraining

Weekly automated retraining pipeline incorporating agent override labels (weighted 2×), with MLflow tracking and instant rollback support.

📥

Structured Ingestion

Accepts plain text, JSON logs (ECS), OpenTelemetry traces (OTLP), and Prometheus Alertmanager payloads with causal context extraction.

Security & Compliance

Enterprise Security Posture

Security is built in at every layer — not bolted on.

🔐

OAuth2 / OIDC Auth

Keycloak or Authentik for authentication. Access tokens expire in 15 min. Refresh tokens expire after 8h inactivity.

👥

RBAC — 4 Roles

viewer, agent, manager, admin — each with scoped permissions. Enforced at API gateway and service level.

🧹

PII Scrubbing

Microsoft Presidio scrubs names, emails, IPs, Aadhaar, phone numbers before any embedding or storage. GDPR + DPDP compliant.

🔒

Encryption

AES-256 at rest. TLS 1.2+ in transit. mTLS between internal services. Secrets via Infisical OSS.

🔎

SAST + CVE Scanning

Bandit + Semgrep on every PR. Trivy scans container images. HIGH/CRITICAL findings block merge and promotion.

📋

Immutable Audit Log

Append-only audit_log table with row-level security. 12-month retention in DB, 5-year archive in MinIO.
