TicketIQ Architecture

Next-Gen AIOps & Intelligence Service Management Framework

Proposed Solution Architecture

TicketIQ is built on a Containerized Hybrid-Microservices architecture. It decouples high-frequency ingestion from heavy-compute Intelligence processing, ensuring infinite scalability and sub-second UI responsiveness.

Component Breakdown:

  • Ingestion Gateway (Traefik): Edge router managing SSL, Load Balancing, and OTLP Tracing.
  • Intelligence Core (FastAPI): Async Python backend orchestrating ML inferences and business logic.
  • Neural Matrix (PostgreSQL + pgvector): Unified relational and vector database for hybrid RAG searches.
  • Mission Control (React + Vite): High-density executive dashboard with glass-morphism aesthetics.
  • Model Registry (MLflow): Life-cycle management for classification and embedding models.

Low-Level Design (LLD)

The LLD focuses on the Singleton Pattern for ML service initialization and the Repository Pattern for data abstraction, ensuring that the Intelligence layers are decoupled from the persistence engine.

Key Services:

  • ClassifierService: Manages the chain of thought (CoT) prompting for Ollama and LLM Judge validation.
  • RAGService: Implements semantic similarity scoring using cosine distance in pgvector.
  • RoutingService: Handles departmental folder assignments and user permission scoping.
  • AuditService: Captures immutable forensic snapshots of ticket states during overrides.

Data Engineering & Pipeline

Our ETL (Extract, Transform, Intelligence) approach utilizes PII Scrubbing at the entry point to ensure GDPR/HIPAA compliance before data ever reaches the vector store.

graph LR Raw[Raw Ticket Input] --> PII[PII Scrubber] PII --> Parser[Structured Input Parser] Parser --> Embedding[Vector Embedding Engine] Embedding --> Index[pgvector Indexing] Index --> Intelligence[Neural Classification]

Data Model (ERD)

The data model is optimized for High-Performance Intelligence Retrieval. The 'Ticket' entity is linked to 'Embeddings' for vector search and 'PatternAlerts' for recurring issue detection.
